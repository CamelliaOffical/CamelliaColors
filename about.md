# Camellia Colors

<cl>Camellia Colors</c> is a lightweight <cg>editor mod</c> built for creators. It lets you instantly export color channels from selected objects into <cy>Color Triggers</c> — in a single click.

# Why?

Every creator knows the pain: after merging parts, you have to <cr>manually recreate all the color triggers</cr> from scratch. It's slow, repetitive, and easy to get wrong.

<cl>Camellia Colors</c> eliminates that entirely.

# How to use

* Select any objects in the editor.
* Hit the <cg>C</c> button next to **Edit Special**.
* A column of <cy>Color Triggers</c> is automatically placed to the left of your selection — one per unique color channel, with colors, opacity and blending already set.
